In this ungraded lab, you are going to experiment with some algorithms that aim to reduce the dimensionality of data. You will be using scikit-learn to implement three of these algorithms on three different types of data:

  1. Principal Component Analysis ( PCA ) on numerical data.

  2. Single Value Decomposition ( SVD ) on image data

  3. Non-negative Matrix Factorization ( NMF ) on text data.
