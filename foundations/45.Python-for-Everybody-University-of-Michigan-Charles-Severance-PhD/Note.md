6. We need remainder operator `%` to put output in a certain range, for example, playing cards or dice to get a number between 1 to 6.

7. Operator precedence rule (High to Low) in python:

- Parentheses
- Exponentiation
- Multiplication and division and remainder
- Addition and subtraction
- Left to Right evaluation in case of same precedence

8. In python 2, 9/2 = 4 but in python 3, 9/2 = 4.5. In python 2, 9//2 = 4 but in python 3, 9//2 = 4.0

9. In case of if-elif-else block. exactly one block out of if, elif and else block should be executed.

In case of if-elif block with no else block, either if or elif block should be executed or no block should be executed.

10. In Try-Except block, if something goes wrong in try block then it exits the try block where something goes wrong and goes to except block and executes the statements.
    

11. For reuse or D.R.Y(Don't Repeat Yourself), we use functions.
