Hello everyone, welcome to a new class. If you are interested to create a dataset for object detection you are going to need not only the images but the annotations. These annotations contain the specific location of different objects into an image and also these annotations contain the specific class name or label. In order to perform this task I'm going to present you a tool which is label.img. You will need to have the images. With this tool you are going to construct your data creating annotations on every image. This is an example. In this picture there are several players. These players are identified with a banding box surrounding every object and for each banding box we need to assign a class, a specific label, that represents this object. In this example the class or label person is selected for these three objects. With this tool you can create annotations in different formats. For this course we are interested in YOLO and XML formats. So, let's take a quick overview. This is the repo in GitHub. You can find some examples. You can also find a procedure for installation. There are several options for Linux, Mac OS, Windows, creating a virtual environment. These are the dependencies for the installation in Windows. You will need these three programs. This is another option, Windows plus anaconda. And also you can get it using pip installer, finally the use on Docker. However, in my experience the easiest way to do that is to use an executable file. Let's check it out. On this webpage you can find different executable files for Windows and Linux. If you select the latest version, for example this, you only need to click here. A new file is downloading in your system so just unzip this file and you will get this. A folder containing data. These are predefined classes that come with this program. You can use them if you want or you can create your own classes. And this is the executable file. You only need to run this file clicking on this icon. The first step is to select an image directory. So, you need to go here on this open directory folder, click here. For instance, I have two folders containing images. You only need to select the specific folder that you want to use for creating annotations. Click on this button. Very good. On this right side you will see the content of this selected folder. There are several images about stop signs. So, how can you create an annotation? Here I'm interested to select this stop sign because this is an object that I want to detect. Then I need to click here on create regbox and now select with your mouse the specific banding box that covers this object. Here I have a small window in order to place the specific class. For example, my class could be a stop sign and these are different suggested classes that you can use. Click on ok and now we have this label assigned to this specific banding box. Very good. Click on next image. Click on yes. Here it's the same. Create regbox. Select the location of this stop sign. Now we have this label automatically. Click on ok. Normally you need to save. Before continue click on save and that's it. We are creating annotations, but what format we are using for? If you see here on the left, this is the default format Pascal VOC. It's an XML file. So, we can change the format for YOLO or we can continue with Pascal VOC. For example, I'm going to select another image. Here I can change the format and create a new regbox. Select the specific area. This is a stop sign. Click on ok. Very good. Click on save and that's it. If you see here, this is the current image illuminated on blue. Finally, I'm going to select another image. Click on regbox. Click on ok. Click on save. Very good. As you can see, it's very simple to create annotations into an image. If you have different objects into an image, you can select all of them creating one annotation. Let's see an example. I have selected another folder containing traffic lights. So, here I have two traffic lights. I only need to create this banding box around this object, but this time the label class is not a stop sign. I need to change the traffic light. Ok. I'm going to create another banding box. The class is the same. Very good. Finally, if I want to select the other class, for example, for this small sign, I can create an annotation and place the corresponding class stop sign. So, in this image I have detected two classes, traffic light and stop sign. There are three annotations for only one image. So, click on save. Very good. Now, let's see the results, the annotations. This is the folder containing the images for stop signs and here I have one annotated image and its annotation file. In this case, XML format. Let's check it out. This is the content of this file containing the file name, the path, the size of the image in three channels, segmented is for object segmentation which is not the case, the name of the object and these are the coordinates of the banding box containing the mean values and the maximum values of the banding box. Very good. This format is for Pascal VOC, but now I have another image and it's annotation but in YOLO format. Let's check it out. Very good. It's more simple. The first number contains the class ID or the label ID and the next four numbers are the information about the banding box. YOLO uses a scale between zero and one. This is a reason for these decimals. Finally, let's check the last example. This is a picture and this is the annotation in YOLO format. Let's check it out.
